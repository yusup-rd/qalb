# Политика конфиденциальности Qalb

**Последнее обновление: 24 октября 2026 года**

Qalb — бесплатное некоммерческое исламское приложение-компаньон. Это личный проект независимого разработчика. По вопросам конфиденциальности и запросам пишите на [yusuprd@icloud.com](mailto:yusuprd@icloud.com).

## Какие данные обрабатывает Qalb

**Местоположение.** При запуске Qalb запрашивает разрешение использовать геоданные, пока приложение открыто. Если вы разрешите доступ, приложение получает текущие координаты устройства. Время намаза и направление Киблы рассчитываются на устройстве; координаты также передаются в API Qalb вместе с языком приложения для определения названия местности. Если этот запрос не сработает, Qalb может передать координаты геокодеру платформы устройства. Когда ближайшие мечети отображаются на главном экране или в разделе мечетей, API Qalb получает ваши координаты, радиус поиска и лимит результатов. Затем Qalb запрашивает автомобильные оценки маршрутов максимум до 20 ближайших мечетей, передавая сервису маршрутизации ваши координаты и координаты мечетей. При запросе маршрута для его построения передаются начальная и конечная точки. Qalb не запрашивает фоновый доступ к местоположению.

**Данные на устройстве.** Qalb хранит на устройстве язык, тему, настройки расчёта времени намаза и уведомлений, параметры отображения Корана, прогресс тасбиха и духовных пауз, последнюю открытую суру, настройку виброотклика компаса и кэш ответов API. Кэш содержит до 100 последних записей; его ключи могут включать округлённые координаты. Текст Корана, английский и русский переводы, английская транслитерация и метаданные чтения загружаются через API Qalb и сохраняются в SQLite после успешной первой синхронизации. Для чтения Корана после новой установки сначала требуется подключение к интернету; после загрузки чтение и поиск работают офлайн. Запросы поиска по Корану и история чтения не отправляются в API Qalb или Quran.Foundation.

**Уведомления.** Если вы включите напоминания о намазе и разрешите уведомления, Qalb рассчитывает время намаза на устройстве и планирует уведомления локально через операционную систему, максимум на семь дней вперёд. Расписание не передаётся службе удалённых push-уведомлений. Содержание уведомления может быть видно людям, имеющим доступ к устройству.

**Сетевые и диагностические данные.** Когда устройство обращается к API Qalb, хостинг API получает обычные данные соединения, например IP-адрес и время запроса. Журнал запросов приложения записывает методы запросов; настроенное журналирование удаляет URL, параметры запроса и маршрута, заголовки авторизации, cookies и referrer. В журналы ошибок могут попадать дополнительные диагностические сведения. Сетевые операторы и сторонние сервисы также могут обрабатывать данные соединения.

## Сервисы, получающие данные

Qalb — независимое приложение и не является официальным приложением Quran.Foundation или Quran.com. API Qalb использует Quran.Foundation Content Sync для поддержки данных Корана, доступных в приложении. Приложение загружает и обновляет локальную копию через API Qalb; оно не обращается напрямую к Quran.Foundation и не отправляет поисковые запросы по Корану или историю чтения ни одному из этих сервисов.

API Qalb передаёт необходимые для соответствующей функции данные следующим сервисам:

- [OpenStreetMap Nominatim](https://operations.osmfoundation.org/policies/nominatim/) получает координаты и язык для определения названия местности.
- [TakbeerTime](https://takbeertime.com/privacy.html) получает координаты, радиус поиска и лимит результатов для поиска ближайших мечетей.
- Публичный сервис маршрутизации [OSRM](https://project-osrm.org/docs/v5.24.0/api/) получает ваши координаты и координаты ближайших мечетей для оценки маршрутов либо начало и конец выбранного маршрута для построения пути.
- [AlAdhan](https://aladhan.com/prayer-times-api) получает запрошенные месяц и год календаря. Координаты для этого запроса Qalb не передаёт.
- [metals.dev](https://metals.dev/policy/terms) получает серверный запрос цен на золото и серебро в долларах США за грамм. Ключ API используется сервером и не включён в приложение.

Карты отображаются через Apple Maps в iOS и Google Maps в Android. Эти поставщики могут получать запросы карт и сведения, используемые для отображения вашего местоположения и выбранных объектов. Если поиск местности через API Qalb не сработает, координаты может получить геокодер платформы устройства. При воспроизведении чтения Корана приложение передаёт аудиозапрос зеркалам [QuranicAudio](https://quranicaudio.com/about); они также получают обычные сетевые данные. При запуске Qalb проверяет наличие обновлений через [Expo Updates](https://expo.dev/privacy); проверка может передавать сведения, например операционную систему устройства и случайный идентификатор обновления.

API Qalb размещён на Render и может использовать Upstash Redis для временного кэширования ответов, если Redis настроен. Upstash получает кэшируемые ответы API и ключи кэша, описанные ниже. Поставщики обрабатывают запросы по собственным условиям и уведомлениям о конфиденциальности; Qalb не контролирует их независимые сроки хранения и места обработки данных.

В Qalb нет аккаунтов, рекламы, аналитики, SDK для отчётов о сбоях, удалённых push-уведомлений, платных функций или обработки платежей. Использование исламского приложения и его функций геолокации может раскрывать религиозные интересы по активности устройства или сети, однако Qalb не создаёт на основе этих сведений профиль пользователя. Связь с разработчиком открывает почтовое приложение; Qalb не отправляет письмо самостоятельно.

## Хранение и сроки

Настройки и загруженная база Корана остаются на устройстве, пока вы не очистите данные Qalb или не удалите приложение. Ответы API считаются актуальными 24 часа для названия местности, результатов поиска мечетей и цен на металлы; один час для маршрутов и их оценки; 30 дней для событий календаря. Устаревшие записи могут оставаться в кэше до его очистки, удаления данных приложения или удаления приложения.

Если Upstash Redis настроен, он временно кэширует результаты поиска мечетей на 15 минут; маршруты и оценки маршрутов — на один час; название местности и цены на металлы — на 24 часа; события календаря — на 30 дней. API также хранит в Redis общий набор данных Quran Content Sync и его ревизию до успешной синхронизации или удаления оператором. Это содержимое поставщика, а не личная история чтения. Redis не используется для аккаунтов или истории действий пользователей. Render указывает, что журналы в панели рабочих пространств Hobby доступны семь дней; фактический план, настройки развёртывания и внешние экспорты журналов могут влиять на срок их доступности. Другие поставщики устанавливают собственные сроки хранения в своих правилах.

## Ваш выбор и запросы о конфиденциальности

Разрешения на геоданные и уведомления можно запретить или отозвать в настройках устройства. Удалить настройки, кэш и другие локальные данные приложения можно очисткой данных Qalb или удалением приложения. Аккаунта Qalb или серверной истории чтения нет. В зависимости от применимого законодательства у вас могут быть дополнительные права в отношении персональной информации. Чтобы задать вопрос о конфиденциальности или направить запрос по сведениям, обрабатываемым Qalb, напишите на [yusuprd@icloud.com](mailto:yusuprd@icloud.com). Не отправляйте по электронной почте чувствительные сведения. По вопросам данных, обрабатываемых сторонними поставщиками, обращайтесь к ним согласно их правилам.

Политика может обновляться при изменении функций Qalb или практик обработки данных. Дата выше указывает на последнюю редакцию.
